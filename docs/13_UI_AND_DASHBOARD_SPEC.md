# UI and Dashboard Specification

## 1. 기본 원칙

- 한 화면에 모든 데이터를 쌓지 않는다.
- 가격보다 데이터 기준일과 품질을 함께 보여준다.
- 원문 사실과 추론을 시각적으로 구분한다.
- 긍정·부정 색상만으로 의미를 전달하지 않는다.
- 결측·지연을 숨기지 않는다.
- 모바일은 후속 최적화, 데스크톱 우선.

---

## 2. 기본 내비게이션

```text
Market
Company
Smart Money
Filings & Events
Valuation Lab
Data Quality
Settings
```

Settings에는 API 키 값을 표시하지 않는다.

---

## 3. Company Dashboard 순서

1. 종목·현재가·기준시각
2. 확률가중 가치와 안전마진
3. 핵심 투자 가설 요약 자리
4. 매크로 영향
5. 차트·상대강도
6. 실적
7. 국내 단기 수급
8. 글로벌 기관 포지션
9. 공시 문구 변화
10. 뉴스·이벤트
11. 위험요인·미확인
12. 데이터 품질

Phase 1에서는 fixture 카드의 골격만 만든다.
