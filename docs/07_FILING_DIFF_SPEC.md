# Filing Sentence Diff Specification

## 1. 목적

정기보고서·공시를 문장 단위로 비교해 다음 변화를 탐지한다.

- 신규 등장
- 삭제
- 내용 수정
- 위치 이동
- 숫자 변경
- 확정성 강화·약화
- 성장 표현 강화·약화
- 위험·불확실성 증가·감소

---

## 2. 비교 단위

### 우선 비교
- 사업보고서 ↔ 사업보고서
- 1분기 ↔ 다음 해 1분기
- 반기 ↔ 다음 해 반기
- 3분기 ↔ 다음 해 3분기

### 보조 비교
- 직전 연속 보고서

문서 유형이 다르면 비교 신뢰도를 낮춘다.

---

## 3. 처리 과정

```text
원문 수집
→ 문서·섹션 추출
→ 반복 헤더·페이지번호 제거
→ 표와 문장 구분
→ 문장 분리
→ 섹션 내 후보 매칭
→ 의미 유사도
→ 숫자·단위 diff
→ 규칙 기반 톤 변화
→ 결과 저장
→ 원문 대조
```

---

## 4. 변화 유형

```text
ADDED
REMOVED
MODIFIED
MOVED
NUMBER_CHANGED
TONE_UP
TONE_DOWN
UNCERTAINTY_UP
UNCERTAINTY_DOWN
RISK_ADDED
RISK_REMOVED
```

한 문장은 복수 태그를 가질 수 있다.

---

## 5. 톤 사전 예시

### 확정성
```text
강: 확정, 반드시, will, shall
중: 계획, 예상, expect, intend
약: 가능, 검토, may, could, consider
조건: 시장 상황에 따라, 필요 시, subject to
```

### 성장
```text
강력한 성장 → 견조한 성장 → 안정적 성장 → 완만한 성장
급증 → 증가 → 유지 → 둔화 → 감소
```

### 위험
```text
영향 없음 → 제한적 영향 → 영향을 받을 수 있음 → 중대한 불확실성
```

한국어와 영어 사전을 분리하고 버전 관리한다.

---

## 6. 오탐 방지

- 문단 이동만으로 삭제·신규 판단하지 않음
- 숫자만 바뀐 문장은 별도 분류
- 표의 열 위치 변경과 실질 값 변경 구분
- 목차·면책·반복문구 제외
- 동일 문장 다중 매칭 제한
- 섹션 범위 밖 매칭은 낮은 신뢰도
- 시스템 판단을 원문 없이 보여주지 않음


## 8. 숫자 변화

숫자는 다음을 구조화한다.

- 값
- 단위
- 통화
- 기간
- 증가·감소
- 문맥

예:
```text
CAPEX 1,000억원 → 700억원
```

단순 문자열 diff와 별도 계산 결과를 모두 보존한다.
